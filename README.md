# TransitWatch (Extended)

Built on top of [Zahid's TransitWatch project](https://github.com/zaidkhalifa/TransitWatch). Added several new features:

- RAPTOR-based multi-modal route finding with transfers across NJT, MTA, and PATH
- GTFS static timetable seeding (timetables, calendars, transfers collections)
- Live vehicle tracking with Kalman filter for smoothed positions
- Historical delay collection and per-segment timing statistics
- Route timing adjustment using past observations
- Map view showing routes and live vehicles for saved commutes
